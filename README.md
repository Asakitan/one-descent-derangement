# 恰有一个降点的错排：首项期望

从 $n$ 元、恰有一个降点的所有错排中均匀抽样，首项期望为 $3-2^{-(n-2)}$（$n\ge2$）。一次性证明两个 OEIS 条目的第一列猜想。
